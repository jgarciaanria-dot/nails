# Vicelly Sánchez Studio Nails — Agenda Virtual

## Archivos
- `index.html` — Página cliente (agenda pública)
- `admin.html` — Panel de administración
- `config.js` — Configuración (credenciales, WhatsApp, Sheet)
- `yappy.js` — Integración Yappy
- `sheets.js` — Integración Google Sheets

## Configuración inicial
1. Abre `config.js`
2. Reemplaza los valores marcados con TU_...
3. Sube los archivos a tu servidor o Vercel/Netlify
